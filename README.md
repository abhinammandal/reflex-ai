# Reflex

> Do it three times. Never do it again.

Reflex is a local-first intelligent automation platform that learns repeated computer workflows and transforms them into safe, user-approved routines.

## Core Principles

- Observe only approved applications and websites.
- Never record passwords, OTPs or payment information.
- Store personal activity locally by default.
- Suggest routines before activating them.
- Allow every routine to be paused or stopped.
- Keep a visible history of automated actions.

## Initial Platform

- Windows desktop application
- Google Chrome extension
- Python intelligence engine
- Local SQLite database

## Project Status

The production foundation is currently under development.
